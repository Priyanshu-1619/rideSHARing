## 🔑 Critical Files for Deployment

**At Repository Root (MUST BE HERE):**
- ✅ `Procfile` - Tells Render how to start the app
- ✅ `requirements.txt` - All Python dependencies
- ✅ `runtime.txt` - Python version (3.11.8)
- ✅ `render.yaml` - Render platform configuration
- ✅ `.gitignore` - Exclude venv, .env, etc.

**In rideshare2/ Directory:**
- ✅ `wsgi.py` - WSGI application entry point
- ✅ `backend/app.py` - Main Flask application
- ✅ `templates/` - HTML templates (must exist)
- ✅ `static/` - CSS, JS files (must exist)

## ⚙️ File Purposes

| File | Purpose | Location |

| `Procfile` | Defines how Render starts the app | Root |
| `requirements.txt` | Lists all pip packages | Root |
| `runtime.txt` | Python version specification | Root |

| `wsgi.py` | WSGI app entry point (Gunicorn-compatible) | rideshare2/ |

### Pushing to GitHub

```bash

git add .
git status  # Review what's being added

```

### On Render Dashboard

1. Connect GitHub repository
2. Auto-detected settings:
   - Python runtime: 3.11
   - Build command: `pip install -r requirements.txt`
   - Start command: `cd rideshare2 && gunicorn -w 4 -b 0.0.0.0:$PORT --timeout 120 wsgi:app`

3. Environment variables:
   - `FLASK_ENV=production`
   - `SECRET_KEY=<auto-generated>`
   - `USE_MYSQL=False`

4. Deploy!

## 🚀 How It Works

```
Render Platform
    ↓
1. Detects Procfile at root
    ↓
2. Installs requirements.txt
    ↓
3. Uses runtime.txt (Python 3.11.8)
    ↓
4. Executes Procfile command:
   cd rideshare2 && gunicorn -w 4 -b 0.0.0.0:$PORT wsgi:app
    ↓
5. Gunicorn loads wsgi.py
    ↓
6. wsgi.py imports app from backend/app.py
    ↓
7. Flask app starts with templates and static files
    ↓
8. Your app is live! 🎉
```

## ⚠️ Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| `ModuleNotFoundError: app` | Ensure `backend/app.py` exists |
| `Static files not loading` | Check `templates/` and `static/` exist |
| `Port binding error` | PORT is auto-set by Render |
| `Database not found` | Database auto-initializes on first run |
| `Import errors` | Check `wsgi.py` sys.path setup |
